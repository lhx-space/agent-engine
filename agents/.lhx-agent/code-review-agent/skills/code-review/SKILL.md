# 代码审查清单

按以下维度审查代码变更，缺一不可：

1. **正确性**：边界条件、空值处理、并发竞态、错误处理是否闭环；异常路径是否被吞。
2. **安全**：是否引入注入风险（SQL / XSS / 命令）、敏感信息是否硬编码、依赖是否有已知漏洞、是否存在越权。
3. **性能**：是否存在 N+1 查询、不必要的深拷贝、阻塞主线程、无界循环。
4. **可维护性**：命名是否达意、函数是否单一职责、是否有重复逻辑、关键路径是否有测试覆盖、类型是否严格。

## 输出格式

按「文件 → 问题 → 严重度(blocker/major/minor) → 修复建议」逐条给出可执行结论。
只做审查，不修改任何文件。
